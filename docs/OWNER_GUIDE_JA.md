# AWAKEN 管理者向け操作ガイド

このガイドは保管用です。今すぐ全項目を操作する必要はありません。送信制限中は新しいログインメールを要求せず、解除後もチャットで1操作ずつ確認してください。

## 今の確認状況

- 管理者のログイン、登録者一覧、絞り込み：実際の画面で確認済み。
- 無料体験の1回制限、会員の7日待ちと7日経過後の再抽選：実際のテストで確認済み。
- 退会予約・取消、管理者予約の保護：ローカルのDBと模擬APIのブラウザーで検証済み。実アカウントでの一連の確認は継続中。
- 新しい事前登録欄：公開コードへ反映済み。管理者画面での実表示・実登録と、初回の認証メールからの会員化は確認待ち。
- 標準認証メールには宛先・送信回数の制限があります。事前登録機能は制限を回避する機能ではありません。

## ログインを保つ使い方

同じ端末・同じブラウザーを使い、普段はログアウトしません。通常のAWAKENページをブックマークして開いてください。メールのログインリンクをブックマークしたり、繰り返し開いたりしないでください。

ログインメールのリンクは通常1回限りです。新しいメールが届いたら、そのメールのリンクだけを普段使うブラウザーで開きます。メールアプリ内のブラウザー、Safari、Chromeはログイン状態が別になることがあります。

自分でログアウトした場合、サイトデータを削除した場合、別のブラウザー・端末を使う場合などは、本人確認をやり直す必要があります。永久にログインを保証するものではありません。

管理者とお客様の両方を試す場合は、可能なら別の端末・ブラウザーを使い、アカウントを切り替えるたびにメールを送り直さないようにします。

## 入金を確認したお客様を事前登録する

1. お客様から、AWAKENで使うメールアドレスを受け取ります。
2. 入金を確認します。AWAKENは決済状況を自動確認しません。
3. 管理画面の「入金確認済みの会員事前登録」にアドレスを入力します。
4. 入力したアドレスと確認画面を確認して、事前登録します。

まだ本人確認をしていない方は「事前登録・初回認証待ち」と表示されます。この管理操作ではメールを送らず、本人確認済みにも変更しません。

お客様には、通常のAWAKENページから事前登録と同じアドレスで初回認証をしてもらいます。本人確認が成功すると会員資格が結び付きます。

すでにメール確認済みの無料体験アカウントなどは、事前登録の管理操作で会員に変更できます。有効な会員への重複事前登録は、回数・7日待ち・退会予約を変更しません。

入力を間違えた場合は、まだ会員化されていない「事前登録」を取り消せます。アカウントやカード記録を削除する操作ではありません。本人確認後に会員化された方には、通常の会員管理操作を使います。

## 一覧を見る

「すべての登録者」「会員だけ」「無料体験」「退会予定」「会員資格終了」「利用停止」「事前登録・初回認証待ち」で絞り込めます。メールアドレスは一部でも検索できます。

表示件数を変更したり、「前へ」「次へ」でページを移動できます。日時は日本時間です。

前回引いた日時が空欄なら、まだ記録がない状態です。「今すぐ」は現在引ける状態、「メール確認後」「初回認証後」は先に本人確認が必要な状態です。

操作後の情報を見直す場合は「最新に更新」を使います。一覧を開くだけでカードを引いたり、利用記録が変わったりすることはありません。

## 会員にする・月末で終了する

未入会・終了済みの方を会員にする場合は、入金を確認してから操作します。会員化直後に1回、その後は前回から168時間後に1回引けます。

すでに有効な会員に繰り返し「会員にする」を押しても、利用回数は増えません。終了予約を取り消す管理操作でも、前回の日時や7日待ちは変わりません。

管理者の「月末で終了」は、日本時間の月末までは7日間隔で利用でき、翌月1日午前0時から新しい抽選を止めます。月末にもう一度操作する必要はありません。

## お客様の退会予約

お客様自身の予約は、月末前なら本人が取り消せます。管理者が設定した終了予約は、お客様から取り消せません。一覧の「お客様／管理者」で予約元を確認できます。

会員資格の終了後は、お客様自身では復活できません。再入会は入金確認後、管理画面から行います。終了後に無料体験が復活することはありません。

これらはAWAKENの会員資格の操作です。外部の決済サービスの継続課金は自動停止しません。継続課金がある場合は、そのサービス側でも必要な手続きをしてください。

## 送信制限が出たとき

ログインメールを続けて再送しないでください。すでにログインできている画面はログアウトせず残します。

標準メールの送信制限は、お客様と管理者で共有するプロジェクト全体の制限です。Supabaseを有料プランにするだけで標準メールが無制限になるわけではありません。本番で多くのお客様に案内する前に、Custom SMTPと送信元の準備が必要です。

メールが届くかどうかの実テスト、GmailとiCloudを切り替える実テストは、制限が解除されてから順番に行います。パスワード、秘密キー、ログインリンク、認証トークンはチャットに貼り付けないでください。

## 制限解除後の確認予定

以下は確認項目の記録です。今まとめて実行する必要はありません。

- 管理画面の「入金確認済みの会員事前登録」欄の表示。
- 本人確認前のテストアドレスを事前登録し、「初回認証待ち」となること。この操作でメールを送らないこと。
- テストアドレスで初回認証後、会員としてすぐ1回引け、その後7日待ちになること。
- 管理者・お客様それぞれが同じブラウザーで開き直して、毎回のメール送信なしで状態を復元できること。
- テストアカウントで本人の退会予約・取消と、管理者予約は本人が取り消せないこと。

実際のお客様の利用日時をテスト目的で変更しないでください。
